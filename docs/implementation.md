# 实现定义与实验口径

本项目实现 `In1_2_2.md` 的正常参照与双轨迹状态对齐结构。候选数据范围采用 `dataset.txt`，指标接口依据 `metrics.txt` 并核对 TAB 提交 `5a7e6f80c405eed7c4dd1390f69fbba2fd8ddcf2`。原方案正文不作修改。

## 机制与代码

| 方案模块 | 实现 | 约束 |
|---|---|---|
| 式 (1) 双历史预测 | `model.HistoryEncoder`、`NormalRepresentation.predict` | 每个通道独立编码；关系分支仅做一次跨变量聚合；目标历史不直接进入自身的关系预测 |
| 多尺度因果 token | `HistoryEncoder.forward` | 32 个逐点 token，加步长 8、32 的右对齐 patch；注意力按原始终点屏蔽未来 token |
| 有界零对角关系 | `NormalRepresentation.project_relation` | 优化后投影；非对角行和 1；上限 `max(0.5,1/(C-1))`；无权重衰减 |
| 37 维描述 | `model.Descriptor` | 5 维幅值与 32 维形态；幅值统计仅拟合训练段完整片段 |
| 边际与联合 VQ | `model.PrototypeMemory` | 联合库每次仅选一个编号并解码整个变量组；解码器不读取当前查询 |
| 原型初始化与清理 | `training.initialize_prototypes`、`revive_unused`、`finalize_memory` | 正常编码均匀初始化；5 轮无分配重置并清除动量；最终未使用原型通过活动掩码移除 |
| 式 (2) 即时证据 | `DualTrajectoryDetector.step` | 有符号预测残差、两种完整描述差异及 3 个来源可用位，共 79 维 |
| 式 (3) 双轨迹与恢复门 | `DualTrajectoryDetector.step` | 共享适配器与 GRU；同一预测上下文；对齐目标严格为旧正常状态 `mN[t-1]` |
| 式 (4) 全局分数 | `DualTrajectoryDetector.head` | 即时证据、状态差与正常状态共同读出；有效通道 logit 取最大 |
| 正常运行点 | `metrics.threshold_from_normal` | 第 `N-floor(alpha*N)` 个升序分数，严格大于报警 |
| 跨块推断 | `features.StreamingDetector` | 标准化历史和状态持续传递；独立记录显式 reset |

`W` 默认按记录长度取 128 或 256，`d` 为 64 或 96；其余网络维度按方案附录实现。短记录窗口降为保留有效训练目标的 32 倍数，最低 32。原型存储容量不超过训练目标数，逐通道有效容量进一步按完整片段数量限制。

关系矩阵在 `C=2` 时唯一外部源权重为 1，在 `C=3` 时两个外部源必为 0.5；后者受约束固定，不具有可学习的非均匀权重。该性质会影响低维数据的关系消融解释。

## 数据与状态边界

TAB 的 `UnFixedDetectScore/Label` 依据 `DETECT_META.csv` 的 `train_lens` 分割，源码中没有为所有候选数据集单独提供可直接重跑的原始数据清洗脚本。本项目复用已处理数据及其读取方式，不把任意清洗策略称为 TAB 官方流程。

无独立验证记录时，官方正常训练前缀的前 80% 用于拟合，后 20% 用于验证。验证目标可以读取紧接之前真实存在的训练历史。最终正常验证分数由选定模型在真实过去上重建状态后得到，仅取验证后缀校准。独立正常验证记录从零状态开始，预热后评分。

官方测试记录默认视为独立记录，历史与状态重置；即使 TAB 的存储文件将训练和测试拼接，也不推断它们连续。只有经来源确认并在清单中显式指定 `test_continuous=true` 才用官方训练前缀重建测试起始状态。独立验证记录不替代这段真实过去。

标准化统计使用 FP64，仅由拟合段的实际观测估计。常量通道尺度为 1；训练段完全无观测的通道由训练数据决定删除，通道顺序和删除列表保存到来源文件。缺测因果前填，记录起点用训练均值。描述与时序状态、logit 均为 FP32。

预测输入带观测掩码，损失只计算观测目标；边际查询要求本通道 32 点完整，联合查询要求全部通道完整。联合不可用时回退到边际；两者均不可用时重置该通道两条状态，但已就绪的预测误差仍可评分。当前通道缺测不参与全局最大值，全通道不可评分时输出无效标记。

## 两阶段任务

阶段一联合优化平均 Huber 预测损失与两类 VQ 损失，使用 AdamW、5 轮 warmup 和正常验证早停。关系矩阵、原型不使用权重衰减。原型重构在 5 个幅值维度和 32 个形态维度之间等权；VQ 包含拟合项与系数 0.25 的承诺项。

阶段二冻结完整正常模型。训练种子固定生成 512 对轨迹，长记录默认 1024 对；验证默认 128 对，种子 1001、1002。四类扰动与单、双事件布局按任务编号均匀轮换，幅度、位置及子类型随机。训练与验证来源段不同，验证供体也仅取训练正常记录。

四类任务为：水平偏移/漂移，噪声增大/停滞，片段错位/重排，保持事件内均值方差的真子集供体替换。后两类至少 4 点以避免无实际变化；其他长度从 `{1,4,16,64,W,2W,4W}` 取可容纳项。常量、严重缺测等原因导致无法生成指定扰动时明确报错，不强行改变扰动语义。

每对任务含 `W` 点真实历史、至多 128 点可评分正常前缀，优先保留 `W+128` 点恢复后缀；短记录按可用长度缩短。事件、前缀和恢复目标均属于指定训练或验证段。无实际观测变化的任务重采样。缺测位置在扰动之后根据扰动轨迹自身的过去重新填充，防止输入带入干净配对轨迹的信息。

每对轨迹的损失权重合计 1，正负各 1/2。正类按事件等权，前 `min(8,L)` 点与非空内部段各分一半。干净配对点、扰动前缀提供正常负类；事件间隔和恢复后缀的负类单点权重为 2，再在负类内部归一化。标签和权重只进入 BCE，不进入冻结表征、证据编码或状态更新。

连续块默认 256，块间传状态并截断梯度。最后不足一块保留；批内变长轨迹填充点不参与损失。检测器使用 Adam、梯度范数裁剪 1，按固定验证任务 BCE 选择检查点。

## 指标与有效性

主指标基于原始报警。ADD 对每个事件从真实起点到第一次实际命中计时，未命中按事件长度计；不先做点调整。恢复拖尾寻找事件结束后首次连续 8 个可评分正常点均无报警的区间，返回该区间起点相对事件结束的距离。下个事件前或记录末尾未确认恢复的事件计为删失，并同时报告观察到的恢复均值和删失比例。

完整时间轴保留预热和缺测点。它们的报警为 0；排序指标使用统一的最低分占位，额外报告有效点 AP/AUC。区间指标不通过删除缺测点重排时间。Affiliation、Range 或单类输入使上游指标无定义时保留 `null` 及原因；单类点级 Precision/Recall/F1 采用显式正类定义修复 TAB 的类别下标问题。这是边界输入处理，常规双类情况直接调用上游实现。

TAB 的 `auc_pr` 使用 Average Precision；Range-AUC 的容忍窗口为真实事件长度中位数；VUS 窗口上限为其中位数的两倍。PA 指标只在补充栏报告。`precision_at_k` 保持 TAB 对二值预测及严格分位比较的原始行为，不作为连续分数 Top-K 的替代。

实体指标先按数据集与种子聚合，再跨数据集等权，最后统计种子均值与样本标准差。缺失值不补齐，汇总同时输出实体覆盖和有效计数。只有一个种子的样本标准差保持空值。

## 已验证与待验证

本地测试覆盖预测隔离、关系约束、共享状态等式、不可用来源回退、缺测、因果前缀不变性、离线/流式/跨块一致性、任务阶段权重、TAB 全部指定分类指标，以及两阶段保存、校准、复用评价和部署模型加载。

完整数据集、CUDA 环境、正式多种子训练与外部完整基线尚未运行。方案的持续覆盖与恢复优势需要正式测量；任务分类损失低不能直接证明对真实异常有效。默认联合原型采用固定变量顺序，跨实体分别训练；通道顺序必须随模型一起保存。逐点重算多尺度 Transformer 的计算成本也需以服务器上的完整单点延迟为准。

现有检测头替代结构用于机制检查，未实施严格参数匹配；来源开关只改变同一冻结表征的检测输入。留一扰动族实验应同时从训练和验证 `families` 中删除该族，并使用新的任务缓存目录。对照方法若改变因果信息或训练数据条件，必须独立标记实验口径。
